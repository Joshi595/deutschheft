At B1 you are expected to have opinions and to express them clearly: in **Schreiben Teil 2** you write a post giving your view on a topic, and in **Sprechen Teil 3** you react to your partner's presentation and discuss it. The grammar you need is already there: *dass* clauses, *weil*, *zwar … aber*, the Konjunktiv II. What makes the difference now is a varied set of **phrases** and a clear **structure**. This chapter gives you both.

## The idea

A good opinion statement has four parts:

1. **Your position**: *Meiner Meinung nach …*
2. **Reasons**, ideally with an example: *…, weil … Zum Beispiel …*
3. **The other side**, which you take seriously: *Zwar …, aber … / Andererseits …*
4. **A conclusion**: *Insgesamt finde ich …*

In a conversation you add two more skills: **reacting** to what someone else says (agreeing, disagreeing, asking), and **politeness**, so that disagreement does not sound rude. German is fairly direct, but softeners like *ich glaube*, *eigentlich* and the Konjunktiv II are used all the time.

## Step by step

<Step n="1" title="Giving your opinion">

| Phrase | Structure |
| --- | --- |
| Ich finde / glaube / denke, dass … | + dass clause (verb last) |
| Ich bin der Meinung, dass … | + dass clause |
| Meiner Meinung nach … / Meiner Ansicht nach … | + verb next (position 1) |
| Ich bin davon überzeugt, dass … | strong |
| Für mich ist wichtig, dass … | |

<Example de="**Meiner Meinung nach** sollten Kinder weniger Zeit am Handy verbringen." en="In my opinion children should spend less time on their phones." />
<Example de="**Ich bin davon überzeugt, dass** Sport in der Schule sehr wichtig ist." en="I am convinced that sport at school is very important." />

Note the word order: *Meiner Meinung nach* takes position 1, so the **verb comes next**.

</Step>

<Step n="2" title="Giving reasons and examples">

| Function | Phrases |
| --- | --- |
| reason | …, weil / da … · …, denn … · Der Grund dafür ist, dass … |
| example | Zum Beispiel … · Ein gutes Beispiel ist … · Ich selbst habe erlebt, dass … |
| adding | Außerdem … · Dazu kommt, dass … · Ein weiterer Vorteil ist … |

<Example de="**Der Grund dafür ist, dass** viele Menschen keine Zeit zum Kochen haben." en="The reason for this is that many people have no time to cook." />
<Example de="**Ich selbst habe erlebt, dass** man im Ausland sehr schnell lernt." en="I have experienced myself that you learn very quickly abroad." />

</Step>

<Step n="3" title="Agreeing">

| Strength | Phrases |
| --- | --- |
| fully | Da hast du völlig Recht. · Genau! · Das sehe ich genauso. · Ich bin ganz deiner Meinung. |
| partly | Da hast du teilweise Recht, aber … · Das stimmt zwar, aber … · Im Prinzip ja, aber … |

<Example de="**Das sehe ich genauso.** Mit dem Fahrrad ist man in der Stadt oft schneller." en="I see it exactly the same way. In the city you are often faster by bike." />
<Example de="**Das stimmt zwar**, **aber** nicht jeder kann mit dem Rad zur Arbeit fahren." en="That is true, but not everyone can cycle to work." />

</Step>

<Step n="4" title="Disagreeing politely">

| Directness | Phrases |
| --- | --- |
| soft | Ich bin mir nicht sicher, ob … · Ich sehe das ein bisschen anders. · Meinst du wirklich? |
| clear | Da bin ich anderer Meinung. · Das sehe ich nicht so. · Da muss ich widersprechen. |

<Example de="**Ich sehe das ein bisschen anders.** Ohne Auto kommt man auf dem Land kaum zur Arbeit." en="I see that a bit differently. Without a car you can hardly get to work in the countryside." />
<Example de="**Da bin ich anderer Meinung**, denn …" en="I disagree there, because …" />

A useful pattern: acknowledge first, then disagree. *Ich verstehe deinen Punkt, **aber** …*

</Step>

<Step n="5" title="Weighing pros and cons">

| Function | Phrases |
| --- | --- |
| pro | Ein Vorteil ist, dass … · Dafür spricht, dass … |
| contra | Ein Nachteil ist, dass … · Dagegen spricht, dass … |
| balance | Einerseits …, andererseits … · Zwar …, aber … · Auf der einen Seite … auf der anderen Seite … |

<Example de="**Einerseits** ist das Leben in der Stadt praktisch, **andererseits** ist es sehr teuer." en="On the one hand city life is convenient, on the other hand it is very expensive." />
<Example de="**Dafür spricht, dass** man im Homeoffice Zeit spart. **Dagegen spricht, dass** man die Kollegen weniger sieht." en="In favour of it is that you save time working from home. Against it is that you see your colleagues less." />

</Step>

<Step n="6" title="Structuring and concluding">

| Stage | Phrases |
| --- | --- |
| start | Zuerst möchte ich … · Zum Thema … möchte ich sagen, dass … |
| order | Erstens … Zweitens … · Zuerst … dann … |
| conclusion | Zusammenfassend kann man sagen, dass … · Insgesamt finde ich … · Deshalb bin ich der Meinung, dass … |

<Example de="**Zuerst möchte ich** sagen, dass das Thema sehr wichtig ist. **Erstens** … **Zweitens** …" en="First I would like to say that the topic is very important. Firstly … Secondly …" />
<Example de="**Zusammenfassend kann man sagen, dass** das Internet mehr Vorteile als Nachteile hat." en="To sum up, one can say that the internet has more advantages than disadvantages." />

</Step>

## Compared with English

<Compare en="**In my opinion**, children should …" de="**Meiner Meinung nach** sollten Kinder …" note="nach comes after Meinung, and the verb comes straight after the phrase." />

<Compare en="**I agree** with you." de="**Ich bin deiner Meinung.** / **Ich stimme dir zu.**" note="Not 'Ich agree'. zustimmen takes the dative." />

<Compare en="You are **right**." de="Du hast **Recht**." note="German says 'you have right'. Not du bist richtig." />

<Compare en="**On the one hand** … **on the other hand** …" de="**Einerseits** … **andererseits** …" note="Each word takes position 1, so the verb follows directly." />

## Typical mistakes

<Mistake wrong="Meiner Meinung nach **Kinder sollten** weniger fernsehen." right="Meiner Meinung nach **sollten Kinder** weniger fernsehen." why="The phrase takes position 1, so the verb comes next." />

<Mistake wrong="Du **bist** richtig." right="Du **hast** Recht." why="'You are right' is du hast Recht. Du bist richtig means 'you are the right person'." />

<Mistake wrong="Ich **denke so**." right="Ich **denke schon**. / Ich glaube **ja**." why="'I think so' is ich denke schon or ich glaube ja." />

<Mistake wrong="Ich stimme **dich** zu." right="Ich stimme **dir** zu." why="zustimmen takes the dative." />

## Summary

<Summary>

| Function | Key phrases |
| --- | --- |
| opinion | Ich finde / bin der Meinung, dass … · Meiner Meinung nach + verb |
| reason, example | weil … · Der Grund dafür ist, dass … · Zum Beispiel … |
| agree | Das sehe ich genauso. · Da hast du Recht. |
| partly agree | Das stimmt zwar, aber … |
| disagree | Ich sehe das anders. · Da bin ich anderer Meinung. |
| pros and cons | Einerseits … andererseits … · Dafür / Dagegen spricht, dass … |
| conclude | Zusammenfassend … · Insgesamt finde ich … |

**Structure:** position → reasons + example → other side → conclusion.

</Summary>
