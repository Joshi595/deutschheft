Where and how you live is a core A1 topic. You may be asked *Wie wohnen Sie?* in the speaking exam; the reading exam regularly uses adverts for flats and rooms; and a common writing task is a message about moving, or an invitation to your new home.

## The idea

Describing a home needs three kinds of sentence, and you already have the grammar for all of them.

- What it has: Die Wohnung **hat** drei Zimmer. (haben + accusative)
- What there is: **Es gibt** einen Balkon. (es gibt + accusative)
- What it is like: Die Küche **ist** klein, aber hell. (sein + adjective)

So this chapter is mostly vocabulary, plus practice with the accusative from chapter 9. Remember the one rule: after *haben* and *es gibt*, a masculine noun takes **einen** or **keinen**.

## Step by step

<Step n="1" title="Flat and house">

| German | English |
| --- | --- |
| die Wohnung | flat, apartment |
| das Haus | house |
| das Zimmer | room |
| die Miete | rent |
| der Vermieter / die Vermieterin | landlord / landlady |
| der Nachbar / die Nachbarin | neighbour |
| der Stock | floor, storey |
| das Erdgeschoss | ground floor |

<Example de="Ich wohne in einer Wohnung." en="I live in a flat." />
<Example de="Wir wohnen in einem Haus mit Garten." en="We live in a house with a garden." />
<Example de="Die Wohnung ist im zweiten Stock." en="The flat is on the second floor." />
<Example de="Die Miete ist sechshundert Euro pro Monat." en="The rent is 600 euros a month." />

In Germany the floor at street level is *das Erdgeschoss*. *Der erste Stock* is one floor up, as in British English.

</Step>

<Step n="2" title="The rooms">

| German | English |
| --- | --- |
| das Wohnzimmer | living room |
| das Schlafzimmer | bedroom |
| das Kinderzimmer | children's room |
| die Küche | kitchen |
| das Bad | bathroom |
| die Toilette | toilet |
| der Flur | hall |
| der Balkon | balcony |
| der Garten | garden |
| der Keller | cellar |

Every word ending in *-zimmer* is neuter, because *das Zimmer* is the last part of the compound.

<Example de="das Wohnzimmer, das Schlafzimmer, die Küche, das Bad." en="living room, bedroom, kitchen, bathroom" />
<Example de="Meine Wohnung hat zwei Zimmer, eine Küche und ein Bad." en="My flat has two rooms, a kitchen and a bathroom." />

</Step>

<Step n="3" title="Furniture">

| der | die | das |
| --- | --- | --- |
| der Tisch (table) | die Lampe (lamp) | das Bett (bed) |
| der Stuhl (chair) | die Dusche (shower) | das Sofa (sofa) |
| der Schrank (cupboard, wardrobe) | die Waschmaschine (washing machine) | das Regal (shelves) |
| der Sessel (armchair) | die Badewanne (bathtub) | das Bild (picture) |
| der Kühlschrank (fridge) | die Tür (door) | das Fenster (window) |
| der Herd (cooker) | | |
| der Teppich (carpet) | | |
| der Fernseher (television) | | |

<Example de="der Schrank, der Kühlschrank, der Herd." en="cupboard, fridge, cooker" />
<Example de="das Bett, das Sofa, das Regal." en="bed, sofa, shelves" />

*die Möbel* (furniture) is always plural in German: *Die Möbel **sind** neu.*

</Step>

<Step n="4" title="What there is: es gibt and haben">

Both are followed by the accusative.

<Example de="In der Küche **gibt es einen** Kühlschrank." en="In the kitchen there is a fridge." />
<Example de="Im Wohnzimmer **gibt es ein** Sofa und **einen** Tisch." en="In the living room there is a sofa and a table." />
<Example de="Die Wohnung **hat einen** Balkon." en="The flat has a balcony." />
<Example de="Es gibt **keinen** Garten." en="There is no garden." />
<Example de="Wir haben **keine** Waschmaschine." en="We do not have a washing machine." />

*es gibt* does not change for the plural: *Es gibt zwei Schlafzimmer.*

</Step>

<Step n="5" title="What it is like">

| Adjective | Opposite |
| --- | --- |
| groß (big) | klein (small) |
| hell (bright) | dunkel (dark) |
| ruhig (quiet) | laut (noisy) |
| neu (new) | alt (old) |
| billig (cheap) | teuer (expensive) |
| schön (nice) | hässlich (ugly) |
| modern | altmodisch (old-fashioned) |
| gemütlich (cosy) | ungemütlich |

<Example de="Das Wohnzimmer ist groß und hell." en="The living room is big and bright." />
<Example de="Die Küche ist klein, aber gemütlich." en="The kitchen is small but cosy." />
<Example de="Die Straße ist sehr laut." en="The street is very noisy." />

**zu** in front of an adjective means *too*:

<Example de="Die Wohnung ist **zu** teuer." en="The flat is too expensive." />
<Example de="Das Zimmer ist **zu** klein." en="The room is too small." />

</Step>

<Step n="6" title="Saying what you think">

<Example de="Wie findest du die Wohnung?" en="What do you think of the flat?" />
<Example de="Ich finde die Wohnung schön." en="I think the flat is nice." />
<Example de="Ich finde **den** Balkon zu klein." en="I think the balcony is too small." />
<Example de="Die Küche gefällt mir." en="I like the kitchen." />

*finden* takes the accusative: *Ich finde **den** Balkon schön.*

</Step>

<Step n="7" title="Reading a flat advert">

Adverts are written in abbreviations. The reading exam expects you to cope with the common ones.

| Abbreviation | Stands for | Meaning |
| --- | --- | --- |
| Zi. | Zimmer | room(s) |
| qm, m² | Quadratmeter | square metres |
| EG | Erdgeschoss | ground floor |
| 2. OG | zweites Obergeschoss | second floor |
| NK | Nebenkosten | extra costs (heating, water) |
| KM / WM | Kaltmiete / Warmmiete | rent without / with extra costs |
| ab sofort | | available now |
| möbliert | | furnished |

<Example de="Drei Zimmer, Küche, Bad, siebzig Quadratmeter, Balkon." en="Three rooms, kitchen, bathroom, 70 square metres, balcony." />
<Example de="Miete: sechshundertfünfzig Euro plus Nebenkosten." en="Rent: 650 euros plus extra costs." />

In Germany a "3-Zimmer-Wohnung" has three rooms **plus** kitchen and bathroom. The kitchen and bathroom are not counted.

</Step>

## Compared with English

<Compare en="**There is** a balcony. **There are** two bedrooms." de="**Es gibt** einen Balkon. **Es gibt** zwei Schlafzimmer." note="English switches between 'is' and 'are'. German es gibt stays the same, and it takes the accusative." />

<Compare en="a three-bedroom flat" de="eine 4-Zimmer-Wohnung" note="English counts bedrooms. German counts all the rooms except kitchen and bathroom, so the living room is included." />

<Compare en="The furniture **is** new." de="Die Möbel **sind** neu." note="'Furniture' is singular in English and plural in German." />

<Compare en="on the first floor (US: second floor)" de="im ersten Stock" note="German counts like British English: the ground floor is not floor one." />

## Typical mistakes

<Mistake wrong="Es gibt **ein** Balkon." right="Es gibt **einen** Balkon." why="es gibt takes the accusative, and Balkon is masculine." />

<Mistake wrong="Es **geben** zwei Zimmer." right="Es **gibt** zwei Zimmer." why="es gibt never changes for the plural." />

<Mistake wrong="Die Möbel **ist** alt." right="Die Möbel **sind** alt." why="Möbel is a plural word." />

<Mistake wrong="Die Wohnung ist **sehr** teuer für mich. (meaning: too expensive)" right="Die Wohnung ist **zu** teuer." why="sehr means very. zu means too, more than is acceptable." />

<Mistake wrong="**das** Küche" right="**die** Küche" why="Küche ends in -e and is feminine. Only the words in -zimmer are neuter." />

## Summary

<Summary>

| To say | Pattern | Example |
| --- | --- | --- |
| what it has | haben + accusative | Die Wohnung hat **einen** Balkon. |
| what there is | es gibt + accusative | Es gibt **keinen** Garten. |
| what it is like | sein + adjective | Die Küche ist hell. |
| too … | zu + adjective | Das Zimmer ist zu klein. |
| your opinion | finden + accusative + adjective | Ich finde **den** Flur dunkel. |

**Rooms:** das Wohnzimmer · das Schlafzimmer · die Küche · das Bad · der Flur · der Balkon.

**Adverts:** Zi. = Zimmer · qm = Quadratmeter · NK = Nebenkosten · EG = Erdgeschoss.

</Summary>
