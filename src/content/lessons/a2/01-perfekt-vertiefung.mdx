At A1 you met the Perfekt in two chapters: with *haben* and with *sein*. At A2 it becomes your main tool. The exam asks you to say what you did at the weekend, to write about a holiday, to explain why you did not come. All of that is Perfekt, so this chapter rebuilds it properly and fills the gaps.

## The idea

A Perfekt sentence has two halves that frame everything else.

**A helper verb in position 2**, either *haben* or *sein*, conjugated for the person. **A participle at the very end**, which never changes.

*Ich **habe** gestern einen Film **gesehen**. Wir **sind** nach Wien **gefahren**.*

So there are only two decisions to make each time: which helper, and which participle. The helper follows a clear rule. The participle follows a pattern for most verbs, and for the rest there are families that share the same vowel change, which makes them far easier to learn than a random list.

## Step by step

<Step n="1" title="Regular participles">

**ge- + stem + -t.** Stems ending in *-t* or *-d* take **-et**.

| Infinitive | Participle |
| --- | --- |
| machen | **ge**mach**t** |
| kaufen | **ge**kauf**t** |
| arbeiten | **ge**arbeit**et** |
| reden | **ge**red**et** |
| regnen | **ge**regn**et** |

<Example de="Ich habe den ganzen Tag gearbeitet." en="I worked all day." />
<Example de="Es hat die ganze Woche geregnet." en="It rained all week." />
<Example de="Wir haben lange geredet." en="We talked for a long time." />

</Step>

<Step n="2" title="Irregular participles come in families">

Irregular participles end in **-en**, and their vowel often changes. The changes repeat, so learn them in groups.

| Pattern | Infinitive | Participle |
| --- | --- | --- |
| **ei → ie** | schreiben | geschr**ie**ben |
| | bleiben | gebl**ie**ben |
| | steigen | gest**ie**gen |
| **ie → o** | fliegen | gefl**o**gen |
| | verlieren | verl**o**ren |
| | ziehen | gez**o**gen |
| **i → u** | finden | gef**u**nden |
| | trinken | getr**u**nken |
| | singen | ges**u**ngen |
| **e → o** | sprechen | gespr**o**chen |
| | helfen | geh**o**lfen |
| | nehmen | gen**o**mmen |
| **no change** | lesen | gelesen |
| | sehen | gesehen |
| | fahren | gefahren |
| | schlafen | geschlafen |

<Example de="Ich habe meinen Schlüssel verloren." en="I have lost my key." />
<Example de="Sie hat ein Lied gesungen." en="She sang a song." />
<Example de="Er ist in den Bus gestiegen." en="He got on the bus." />

A few are simply odd and have to be learned: *essen → gegessen, sitzen → gesessen, stehen → gestanden, gehen → gegangen, tun → getan, sein → gewesen, werden → geworden*.

</Step>

<Step n="3" title="Mixed verbs: a new vowel, but -t">

A small group changes the vowel like an irregular verb and ends in **-t** like a regular one.

| Infinitive | Participle | Meaning |
| --- | --- | --- |
| bringen | gebr**a**ch**t** | brought |
| denken | ged**a**ch**t** | thought |
| kennen | gek**a**nn**t** | known |
| wissen | gew**u**ss**t** | known |
| rennen | ger**a**nn**t** | run |

<Example de="Ich habe dir etwas mitgebracht." en="I have brought you something." />
<Example de="Das habe ich nicht gewusst." en="I did not know that." />
<Example de="Ich habe an dich gedacht." en="I thought of you." />

</Step>

<Step n="4" title="Prefixes: separable or not?">

This decides where **ge-** goes, or whether there is one at all.

**Separable prefixes** are stressed and can stand alone as words: *ab-, an-, auf-, aus-, ein-, mit-, vor-, zu-, zurück-, weg-*. The **ge-** goes in the middle.

| Infinitive | Participle |
| --- | --- |
| aufstehen | auf**ge**standen |
| einkaufen | ein**ge**kauft |
| mitbringen | mit**ge**bracht |
| zurückkommen | zurück**ge**kommen |
| anfangen | an**ge**fangen |

**Inseparable prefixes** are never stressed: **be-, ge-, er-, ver-, zer-, ent-, emp-, miss-**. They take **no ge-** at all.

| Infinitive | Participle |
| --- | --- |
| besuchen | besucht |
| bekommen | bekommen |
| erzählen | erzählt |
| verstehen | verstanden |
| vergessen | vergessen |
| empfehlen | empfohlen |
| gefallen | gefallen |

<Example de="Wann bist du **auf**gestanden?" en="When did you get up?" />
<Example de="Ich habe einen Brief **be**kommen." en="I received a letter." />
<Example de="Er hat mir alles **er**zählt." en="He told me everything." />
<Example de="Der Film hat mir gut **ge**fallen." en="I liked the film a lot." />

The test is the stress. Say the infinitive aloud: **AUF**stehen has the stress on the prefix, so it separates. be**SU**chen has the stress on the stem, so it does not.

Verbs in **-ieren** also take no *ge-*: *studiert, telefoniert, probiert, passiert, repariert*.

</Step>

<Step n="5" title="haben or sein">

**sein** for a verb that describes **movement from one place to another** or a **change of state**, and that has **no direct object**. Everything else takes **haben**.

| With sein | Why |
| --- | --- |
| gehen, fahren, kommen, fliegen, laufen, reisen | movement from A to B |
| aufstehen, einschlafen, aufwachen, wachsen, sterben | change of state |
| werden, passieren, geschehen | something comes about |
| **bleiben, sein** | exceptions: learn them |

<Example de="Wir **sind** nach Italien **gefahren**." en="We went to Italy." />
<Example de="Das Kind **ist** schnell **gewachsen**." en="The child has grown fast." />
<Example de="Was **ist** **passiert**?" en="What happened?" />
<Example de="Ich **bin** zu Hause **geblieben**." en="I stayed at home." />

Compare pairs that look similar:

| haben | sein |
| --- | --- |
| Ich **habe** gut geschlafen. (a state) | Ich **bin** sofort eingeschlafen. (a change) |
| Ich **habe** im Park gesessen. | Ich **bin** in den Park gegangen. |
| Ich **habe** eine Stunde getanzt. (an activity) | Ich **bin** nach Hause gelaufen. (A to B) |

In southern Germany, Austria and Switzerland you will hear *sein* with *sitzen, stehen* and *liegen* (*Ich bin gesessen*). Both are understood; the exam accepts *haben*.

</Step>

<Step n="6" title="Experience: schon einmal and noch nie">

<Example de="Warst du **schon einmal** in Berlin?" en="Have you ever been to Berlin?" />
<Example de="Ja, ich bin **schon zweimal** dort gewesen." en="Yes, I have been there twice." />
<Example de="Nein, ich war **noch nie** in Berlin." en="No, I have never been to Berlin." />
<Example de="Hast du **schon** gegessen? Nein, **noch nicht**." en="Have you eaten yet? No, not yet." />

| German | English |
| --- | --- |
| schon | already; yet (in questions) |
| schon einmal | ever, once before |
| noch nie | never (so far) |
| noch nicht | not yet |
| gerade | just now |

</Step>

<Step n="7" title="When not to use the Perfekt">

Three kinds of verb normally go into the short past (the Präteritum) instead, even in conversation:

- **sein:** *Ich **war** krank*, rather than *Ich bin krank gewesen*.
- **haben:** *Ich **hatte** keine Zeit*, rather than *Ich habe keine Zeit gehabt*.
- **the modal verbs:** *Ich **konnte** nicht kommen.* These are the subject of the next chapter.

<Example de="Gestern **war** ich müde und **hatte** Kopfschmerzen. Ich **bin** früh ins Bett **gegangen**." en="Yesterday I was tired and had a headache. I went to bed early." />

That sentence is typical spoken German: *war* and *hatte* in the Präteritum, everything else in the Perfekt.

</Step>

## Compared with English

<Compare en="I **went** to Berlin yesterday." de="Ich **bin** gestern nach Berlin **gefahren**." note="English must use the simple past with 'yesterday'. German uses the Perfekt, and for a movement verb the helper is sein." />

<Compare en="I **have lived** here for two years." de="Ich **wohne** seit zwei Jahren hier." note="The reverse trap. For something that is still going on, English uses the perfect and German uses the present with seit." />

<Compare en="sing, sang, **sung** · drink, drank, **drunk**" de="singen, **gesungen** · trinken, **getrunken**" note="The i → u family is the same in both languages. English and German share many of their irregular verbs." />

<Compare en="**Have** you **ever** been to Berlin?" de="**Warst** du **schon einmal** in Berlin?" note="English uses the perfect for experience. German usually prefers war with schon einmal." />

## Typical mistakes

<Mistake wrong="Ich habe meine Tante **gebesucht**." right="Ich habe meine Tante **besucht**." why="be- is an inseparable prefix. Such verbs take no ge-." />

<Mistake wrong="Ich bin um sieben **geaufstanden**." right="Ich bin um sieben **aufgestanden**." why="In a separable verb, ge- goes between the prefix and the stem." />

<Mistake wrong="Ich **habe** nach Hause gegangen." right="Ich **bin** nach Hause gegangen." why="gehen is movement from one place to another and takes sein." />

<Mistake wrong="Ich habe ihn nicht **gekennt**." right="Ich habe ihn nicht **gekannt**." why="kennen is a mixed verb: the vowel changes to a." />

<Mistake wrong="Ich habe drei Jahre in Köln **gewohnt** (and you still live there)." right="Ich **wohne seit** drei Jahren in Köln." why="The Perfekt says it is over. If you still live there, use the present with seit." />

## Summary

<Summary>

| Verb type | Participle | Example |
| --- | --- | --- |
| regular | ge + stem + (e)t | gemacht, gearbeitet |
| irregular | ge + stem + en | geschrieben, gefunden, gesprochen |
| mixed | ge + new vowel + t | gebracht, gedacht, gewusst |
| separable | prefix + ge + … | aufgestanden, eingekauft |
| inseparable (be-, ver-, er-, ent-, ge-) | no ge- | besucht, verstanden, bekommen |
| -ieren | no ge-, -t | studiert, passiert |

**sein:** movement A to B · change of state · bleiben, sein, werden, passieren. **Otherwise haben.**

**Short past instead of Perfekt:** war · hatte · konnte, musste, wollte.

**Experience:** schon einmal · noch nie · schon · noch nicht.

</Summary>
